# Technology Capability Map

## Purpose

Map technology capabilities so teams can identify platform gaps, duplication, and modernization opportunities.

## Capability Areas

- platform engineering
- integration
- identity and security
- observability
- automation
- data and analytics
- governance tooling

## How To Use

- compare current to target capability levels
- identify missing platform functions
- use the map to guide roadmaps

## Use

Use this map to identify which technical capabilities need to be added, standardized, or simplified.
